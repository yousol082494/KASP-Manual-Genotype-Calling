# KASP Manual Genotype Caller

A Python-based tool for manual genotype calling and visualization of Kompetitive Allele Specific PCR (KASP) fluorescence data.

## Features
- Genotype calling based on fluorescence signals
- Manual review and adjustment of genotype assignments
- Export of genotype calling results

## Installation

```bash
pip install streamlit pandas numpy plotly openpyxl
```

## Usage

Run the application using:

```bash
python -m streamlit run kasp_app_manual.py
```

## Requirements
- Python 3
- Streamlit
- pandas
- NumPy
- Plotly
- openpyxl
